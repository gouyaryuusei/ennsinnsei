===============================================================
  EBT: 全身ポーズ認識＆ネガティブ速度チェッカー 【オフライン起動ガイド】
===============================================================

このアプリは、インターネット接続が一切ない環境でも完全に動作します。

---------------------------------------------------------------
■ 起動方法
---------------------------------------------------------------
1. 「起動_オフライン.bat」をダブルクリックしてください。
2. 自動的に黒い画面（ローカルサーバー）が立ち上がり、
   お使いのブラウザでアプリ（http://localhost:8080/index.html）が開きます。
3. 終了したいときは、黒い画面を「×」で閉じるか、「Ctrl + C」キーを押してください。

※ Chrome / Edge などの最新ブラウザでご利用いただけます。
※ 特別なソフト（Python や Node.js 等）をインストールする必要はありません。

---------------------------------------------------------------
■ 特徴とポイント
---------------------------------------------------------------
・MediaPipe Pose（AIモデル・WebAssemblyなど）の必要ファイルを
  すべて本フォルダ内の「mediapipe」フォルダに同梱済みです。
・ブラウザのセキュリティ仕様上、直接 index.html をダブルクリックして開く
  （file:///）とAIモデルの読込が遮断されるため、「起動_オフライン.bat」から
  開くことで正常にAI姿勢推定が機能します。
・PWA（Progressive Web App）に対応しており、ブラウザのアドレスバー右側から
  「アプリをインストール」して単体アプリとして起動することも可能です。
